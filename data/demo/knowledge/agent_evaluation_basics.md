# Agent 评测的基本规则

Agent 评测需要区分程序指标和人工判断。程序指标由确定性代码计算，例如路由是否
正确、引用编号是否合法、关键词是否命中和工具是否按预期调用。每条程序指标都应
记录 evaluator 名称和版本，以便同一输入在相同配置下重新计算。

人工评分由评审人依据固定版本的量表给出。人工评分必须记录评审人、量表版本、
状态和修订号。草稿只用于评审进度，不进入正式分数均值；提交后的纠错通过新修订
完成，不能覆盖旧评分。

程序评分和人工评分可以在同一份报告中并列展示，但不能静默合并成一个总分。如果
业务确实需要综合分，公式、权重和版本必须显式记录。

评测报告应同时给出样本总数、已评分数量和缺失数量。只展示均值会掩盖未完成案例，
因此完成率也是评测结论的一部分。
