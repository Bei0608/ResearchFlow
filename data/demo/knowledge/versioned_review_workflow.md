# 可复现的版本化评审流程

一次可复现的 Agent 评测运行需要冻结 Agent 配置、评测集版本、量表版本和代码提交
标识。已经发布的版本不能原地修改；修正评测问题或评分准则时，应创建新版本。

评审流程依次为：打开任务、查看输入和候选回答、查看证据与程序指标、填写人工量表、
保存草稿、修改、提交。保存草稿后重新进入仍应恢复内容。已提交评分如需纠错，应
创建新的修订并保留旧记录。

统计只使用最新的有效提交，同时单独显示草稿数、已提交数和未评审数。报告应包含
运行配置、程序指标、人工指标、失败案例、基线对比和质量门禁结论。

演示系统可以加载预生成的 Agent 输出和程序指标，以便在没有外部模型服务时完成
人工评审。但预生成数据必须标记为 demo，不能伪装成线上生产流量。
